# AIS Leasing Prototype

Кликабельный прототип АИС «Лизинг» (Next.js 15 App Router + TypeScript, Prisma + SQLite, Tailwind CSS).

## Запуск

```bash
npm install
npm run db:reset   # пересоздать БД и засеять демо-данные
npm run dev        # http://127.0.0.1:3000
```

## Команды

| Команда | Назначение |
|---------|-----------|
| `npm run dev` | dev-сервер |
| `npm run build` | production-сборка |
| `npm test` | тесты расчёта графика и скоринга (vitest) |
| `npm run test:e2e` | сквозной сценарий серверных действий (мутирует dev.db — запускать после `db:reset`) |
| `npm run typecheck` | проверка типов (tsc --noEmit) |
| `npm run lint` | линтинг (ESLint 9 + Next) |
| `npm run db:reset` | сброс БД и повторный сид |

## Демо-пользователи

Сессия привязывается к ROLE-01 (Менеджер по продажам).
Переключатель ролей в шапке страницы.

| Роль | Описание |
|------|----------|
| ROLE-01 | Менеджер по продажам (автор заявок и клиентов) |
| ROLE-02 | Руководитель продаж |
| ROLE-03 | Кредитный аналитик |
| ROLE-04 | Риск-менеджер |
| ROLE-05 | Руководитель риск-подразделения (оверрайд SOFT-факторов) |
| ROLE-06 | Служба безопасности |
| ROLE-07 | ПОД/ФТ |
| ROLE-08 | Юрист |
| ROLE-09 | Лизинговые операции (договоры, мониторинг) |
| ROLE-10 | Бюджетирование |
| ROLE-11 | Бухгалтерия (платежи, импорт выписки) |
| ROLE-12 | Мониторинг |
| ROLE-13 | Взыскание |
| ROLE-14 | Член кредитного комитета |
| ROLE-15 | Руководство |
| ROLE-16 | Внутренний аудит |
| ROLE-17 | Системный администратор (время, все модули) |
| ROLE-18 | Клиент (личный кабинет) |

## Ключевые особенности

- **Деньги** — все суммы в `decimal.js` (тенге), без плавающей арифметики.
- **Скоринг** — формулы (`factsFor` из финансов клиента), стоп-факторы (SOFT/HARD), лимиты на клиента/группу/отрасль.
- **Электронное досье** — категории документов, SHA-256, сроки действия, связанные лица и аудит добавления.
- **Финансы и ПОД/ФТ** — три исторических финансовых периода, история рейтинга и воспроизводимые AML-проверки с повторной идентификацией.
- **Маршруты согласования** — role-based, SLA в рабочих часах, maker-checker (автор не голосует).
- **Оверрайды** — только ROLE-05 может снять SOFT-фактор с обоснованием (аудит + лимит на сделку).
- **Заседания комитета** — виртуальные сессии, голосование членов (ROLE-14/15/02), пересчёт риск-профиля на актуальную дату.
- **Просрочка** — bucketизация по системной дате, пересчёт при перемотке времени.
- **Временной симулятор** — роль ROLE-17 (Системный администратор) перематывает системную дату (+1–3660 дней).
- **CSV-импорт** — загрузка банковской выписки (`mocks/bank-statement.csv`), автоматическая привязка платежей к открытым строкам графиков.
- **Расширенный маршрут** — при лимите или SOFT-стоп-факторе маршрут автоматически расширяется до 7 шагов; готовый демо-кейс — крупная заявка Z-2025-131 в сиде.
- **Расчёт прибыльности** — целевые диапазоны NIM, RoE, RoA.
