# Демо-сценарий

Прогон вручную (dev-сервер на http://127.0.0.1:3000). Роли переключаются в шапке.

## Легенда
Демо-пользователь: **Айдар Сатпаев (ROLE-01, Кредитный специалист)** — автор заявок.
Все дальнейшие действия от имени других ролей — через переключатель.

## 1. Дашборд и клиенты
- Дашборд `/`: статистика (портфель, заявки, просрочка), мои задачи, ожидающие SLA.
- Вкладка «Клиенты»: карточка клиента → табы «Заявки / Договоры / Финансы», сбор-факты скоринга.
- Создать клиента (ROLE-01 умеет).

## 2. Заявка: расчёт, скоринг, отправка
- `/calculator`: ввести параметры лизинга → аннуитетный график (деньги, НДС 12%), сохранить.
- `/applications/new`: клиент + предмет + финансирование → авто-скоринг и стоп-факторы.
- В карточке заявки: сводка оценки риска, стоп-факторы (SOFT/HARD), лимиты, график платежей.
- Кнопка «Отправить на рассмотрение» → маршрут построен автоматически.

## 3. Согласование по ролям
Поочерёдно переключайте роли из маршрута заявки и нажимайте «Утвердить» (каждый шаг — аудит):
- ROLE-02 Руководитель КС → ROLE-03 Аналитик → ROLE-05 Руководитель рисков → ROLE-06 Финансовый директор.
- Если заявка ушла на комитет: вкладка `/committee` — сессия, голосование, кворум, результат.

## 4. Оверрайд стоп-фактора
Заявка с SOFT-стоп-фактором: ROLE-05 может снять фактор с обоснованием (форма с номером фактора).
HARD-фактор оверрайдиться не должен (проверка ограничена).

## 5. Договор и график
- Только по одобренной заявке (ROLE-09 Операционист) → `/contracts/new`: выбор заявки, формирование договора, активный график.
- Карточка договора: график платежей с статусом строк, полей paidTotal; «подписан».

## 6. Платежи
- `/payments`: ввод разового платежа по графику (PaymentForm) → пересчёт paid/остаток, аллокации, аудит.
- Импорт `mocks/bank-statement.csv` → авто-привязка к договорам (источник IMPORT).

## 7. Просрочка и время
- `/overdue`: просроченные строки по системной дате (bucketизация 1д/2-30д/31-60д/61-90д/90+).
- Админ-панель `/admin` → «Симулятор времени» (ROLE-16): перемотать дату → просрочка и SLA пересчитаются.

## 8. Сводные вкладки
- `/portfolio`: pie по EWS, новая выдача по месяцам, маршруты.
- `/search`: поиск клиентов, заявок, договоров.
- `/audit`: полный журнал действий (кто/что/когда).
- `/account`: профиль, сессии, уведомления.

## Базовая проверка после прогона
- Нет 500 на страницах; валидация форм (zod) показывает осмысленные сообщения.
- Изменения отражаются в аудите; просрочка и SLA живут «системным временем».
- `npm run typecheck && npm run lint && npm test && npm run build` — зелёные.
